# Startup idea quiz (web)

A visitor answers 10 multiple-choice questions and gets 2 researched startup ideas in full. If they join the community with their email, they are invited to Circle and emailed 20 more matched ideas plus a personal link to the idea database.

## How it works

- **No AI call per visitor.** The ideas in `data/ideas.json` were researched and tagged once (see the `/startup-ideas library` skill mode). `lib/match.js` filters and ranks them against the quiz answers in plain code, so a quiz run costs nothing.
- **Nothing stored before signup.** `/api/match` returns a signed code that carries the answers. The browser keeps it (and the results link contains it). When the visitor joins, the same 20 ideas are recomputed from the code.
- **Joining** (`/api/join`) looks the email up in Circle, invites it if new, emails the 20 ideas through Resend, and logs the lead. The email holds a signed member link to `/ideas.html`, which shows their ideas and the database.
- **Thin coverage.** If fewer than 26 ideas fit, the matcher first adds ideas from other markets that can be adapted (and says so on the card), then loosens the time and budget limits by one step. Each time, it logs a `coverage_gap` line with the answers, which tells you which niches to research next.

## Run it

```
cd web
npm run dev      # http://localhost:3000
npm test         # matcher checks over 3,000 random quiz runs
```

Without keys it runs in test mode: Circle invites are skipped, emails are written to `.outbox/`, and the join response includes the member link.

## Settings (see `.env.example`)

| Variable | Needed for |
|---|---|
| `QUIZ_SECRET` | Signing links. Required in production. |
| `SITE_URL` | The address used in emailed links |
| `CIRCLE_API_TOKEN`, `CIRCLE_SPACE_IDS`, `CIRCLE_TAG_IDS`, `CIRCLE_COMMUNITY_URL` | The Circle invite |
| `RESEND_API_KEY`, `EMAIL_FROM` | The ideas email |
| `LEADS_WEBHOOK_URL` | Optional copy of each lead (Zapier, Make, Airtable) |

**Before launch:** the Circle call has not been run against a live community. Run `CIRCLE_API_TOKEN=... npm run check:circle <a member's email>` first. If it returns 401, set `CIRCLE_AUTH_SCHEME=Token`.

## Deploy

Built for Vercel with no build step: static files from `public/`, functions from `api/`. Set the project root to `web/` and add the variables above.

## Files

- `public/`: landing page, quiz, results (`index.html`, `app.js`), members' page (`ideas.html`), shared rendering (`ui.js`)
- `api/`: `quiz`, `match`, `join`, `ideas`, `health`
- `lib/`: `quiz.json` (questions), `match.js` (matcher), `token.js` (signed codes), `circle.js`, `email.js`
- `data/ideas.json`: the library, generated by `.claude/skills/startup-ideas/scripts/library.py build`
