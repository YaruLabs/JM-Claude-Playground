## How to Use This Data

### Filter in Spreadsheet:
1. **To see only recommended ideas:** Filter `status` = "RECOMMENDED"
2. **To hide skipped ideas:** Filter `status` != "SKIP"
3. **To find easiest builds:** Filter `technical_grade` = "A" or "B"
4. **To avoid domain expertise:** Filter `domain_barrier` = "None"

### Column Definitions:

| Column | Values | Meaning |
|--------|--------|---------|
| `status` | RECOMMENDED/CAUTION/SKIP | Overall recommendation |
| `viability_score` | 1-5 | Higher = better for solopreneurs |
| `technical_grade` | A/B/C/D | A=Easy, D=Need technical cofounder |
| `domain_barrier` | None/Low/Medium/High | Domain expertise required |
| `monetization` | Strong/Moderate/Weak/Unlikely | Will people pay? |
| `ai_wrapper_test` | Pass/Fail | Fail = ChatGPT does this free |
| `duplicate_of` | ID or blank | Points to similar/duplicate idea |
| `tier` | 2/3/4 | 2=Start Here, 3=Caution, 4=Skip |
