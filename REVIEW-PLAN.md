# Startup Ideas Review Plan
## For Bootstrapping Solopreneurs (<$5K Budget, No Technical Expertise)

---

## The Real Question

> "Can a non-technical solopreneur with under $5K actually build this, launch it, and make money from it?"

Many ideas that *sound* good fail this test because:
1. They're **AI wrappers** that ChatGPT does for free
2. They require **technical complexity** beyond vibe coding
3. They need **domain expertise** or licenses the founder doesn't have
4. The market **won't pay** because free alternatives exist
5. The **competition** is too strong (VC-funded, established players)

---

## Evaluation Framework

### 1. VIABILITY SCORE (1-5)
Overall assessment: Is this a good idea for our target founder?

| Score | Meaning |
|-------|---------|
| 5 | **Excellent** - High confidence a non-technical solopreneur can build and monetize |
| 4 | **Good** - Viable with some effort, clear path to revenue |
| 3 | **Maybe** - Possible but has significant challenges or risks |
| 2 | **Difficult** - Requires skills/resources most solopreneurs lack |
| 1 | **Not Recommended** - Wrong fit for this founder profile |

### 2. TECHNICAL REALITY CHECK (A/B/C/D)
Can a vibe coder with Cursor/Claude Code actually build this?

| Grade | Meaning | Examples |
|-------|---------|----------|
| A | **Easy Build** - Standard CRUD app, simple API calls, basic UI | Landing pages, form tools, content generators |
| B | **Moderate** - Some complexity but doable with AI assistance | Chrome extensions, Shopify apps, simple dashboards |
| C | **Challenging** - Requires debugging, integrations, or edge cases | Real-time features, complex auth, file processing |
| D | **Technical Founder Needed** - Beyond vibe coding capabilities | ML models, complex infrastructure, security-critical |

### 3. DOMAIN BARRIER (None/Low/Medium/High)
Does the founder need special knowledge or credentials?

| Level | Meaning | Examples |
|-------|---------|----------|
| None | Anyone can do this | Content tools, productivity apps |
| Low | General business knowledge helps | B2B tools, marketing software |
| Medium | Industry familiarity required | Vertical SaaS for specific industries |
| High | License/credential/deep expertise needed | Legal, medical, financial advice |

### 4. MONETIZATION REALITY (Strong/Moderate/Weak/Unlikely)
Will people actually pay for this?

| Level | Meaning | Red Flags |
|-------|---------|-----------|
| Strong | Clear willingness to pay, proven market | - |
| Moderate | People might pay, needs positioning | Crowded market |
| Weak | Hard to charge, free alternatives exist | ChatGPT does this |
| Unlikely | No clear path to revenue | Just a feature, not a product |

### 5. AI WRAPPER TEST
Is this just wrapping ChatGPT with a thin UI?

- **FAIL**: User could do this in ChatGPT with a good prompt
- **PASS**: Adds real value beyond what ChatGPT provides (workflow, integrations, automation, domain-specific UI)

---

## Red Flags to Watch For

### Technical Red Flags 🚩
- Real-time collaboration or sync
- Complex file processing (video, audio at scale)
- Security-critical features (payments, auth, PII)
- Custom ML/AI models (not just API calls)
- Complex integrations with enterprise systems

### Market Red Flags 🚩
- "AI [noun] generator" with no differentiation
- Consumer product (hard to monetize)
- Competing with free tools (Notion, Google, ChatGPT)
- No clear ICP (ideal customer profile)
- Solution looking for a problem

### Domain Red Flags 🚩
- Legal advice (unauthorized practice of law)
- Medical/health recommendations
- Financial advice (SEC/FINRA regulations)
- HR/employment decisions (discrimination risk)
- Anything with "compliance" that requires actual expertise

## Review Process

### Phase 1: Duplicate Detection
- Scan all 300 ideas for duplicates or near-duplicates
- Merge or remove redundant entries
- Document removals

### Phase 2: Evaluation Pass
For each idea, assign:
1. Viability Score (1-5)
2. Technical Grade (A/B/C/D)
3. Domain Barrier (None/Low/Medium/High)
4. Monetization Reality (Strong/Moderate/Weak/Unlikely)
5. AI Wrapper Test (Pass/Fail)
6. Brief Notes (red flags, opportunities, concerns)

### Phase 3: Categorization
Group ideas into actionable tiers:

**Tier 1: "Start Here"** (Viability 5, Tech A-B, Domain None-Low, Monetization Strong)
- Best ideas for our target founder
- Clear path to $1K+ MRR

**Tier 2: "Good Options"** (Viability 4, Tech A-C, Domain None-Medium, Monetization Moderate+)
- Solid ideas with some challenges
- May need more effort or positioning

**Tier 3: "Proceed with Caution"** (Viability 3)
- Has potential but significant risks
- Founder should understand the challenges

**Tier 4: "Not Recommended"** (Viability 1-2)
- Wrong fit for non-technical solopreneurs
- Better suited for technical founders or funded startups

### Phase 4: Final Output
Create updated CSV with new columns:
- `viability_score` (1-5)
- `technical_grade` (A/B/C/D)
- `domain_barrier` (None/Low/Medium/High)
- `monetization_reality` (Strong/Moderate/Weak/Unlikely)
- `ai_wrapper_test` (Pass/Fail)
- `tier` (1/2/3/4)
- `review_notes` (brief explanation)
- `recommended_for` (who should build this)

## Success Criteria

After this review, a solopreneur should be able to:
1. Filter to Tier 1 ideas and pick one confidently
2. Understand why an idea is/isn't right for them
3. See the honest assessment of technical and domain requirements
4. Avoid wasting time on ideas that won't make money
